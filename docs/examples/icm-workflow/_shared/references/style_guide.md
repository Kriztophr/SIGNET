# Project Style Guide (shared reference)

- Spelling: US English unless the target publication differs.
- Numbers: spell out zero–nine; use digits for 10+; always use digits with units (5 kg, 3 %).
- Citations inline as `[Source Name](url)`. No footnote-only citations in drafts.
- Uncertainty markers: `[UNVERIFIED]`, `[ASSUMPTION]`, `[TO-CONFIRM]`. Never delete these silently.
- Headings: sentence case. Max depth H3 inside stage artifacts, H4 inside the final draft only.
- Tables preferred over prose for anything with three or more parallel dimensions.
