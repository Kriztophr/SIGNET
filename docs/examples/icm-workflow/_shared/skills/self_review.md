# Skill — Self-review

## When to load
Stage 4, after `draft_v1.md` is complete, before writing `handoff.md`.

## Review passes (run in order)

### Pass 1 — Claims coverage
For each row in `claims_map.md`, locate the corresponding sentence in the draft. Record hit/miss in `self_review.md`. Any miss must be either added to the draft (if trivial) or logged as dropped in `handoff.md`.

### Pass 2 — Citation coverage
Count factual sentences per section. Count inline citations per section. They should be equal or the delta should be justified (definitional sentences and transitions do not need citations).

### Pass 3 — Length
Word count against target. If outside ±10 %, do a compression or expansion pass. Do not add new claims to expand.

### Pass 4 — Tone
Re-read the hook and conclusion aloud (or simulate). If they slip into marketing register, rewrite.

### Pass 5 — Hedging discipline
For every `LOW` and `CONFLICT` claim, verify the sentence uses appropriate hedging. Flag any that assert confidently.

## Output
`self_review.md` uses the schema in the Stage 4 contract. Include a one-line **verdict**: `READY-FOR-REVIEW` or `DRAFT-BLOCKED`.
