# Publication target (example)

- Venue: Ghost newsletter (client instance)
- Endpoint: Admin API `/admin/posts`
- Auth: bearer token stored in reviewer's secret manager (not in this repo)
- Front matter fields required: title, custom_excerpt, tags (max 5), feature_image, feature_image_alt, canonical_url
- Image spec: 1600×840 px, ≤ 300 KB, WebP or JPEG
- Tags allowlist: `ai-governance`, `eu-ai-act`, `healthcare-ai`, `compliance`, `post-market-monitoring`
