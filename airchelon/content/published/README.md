# Published pieces

A piece lands in this directory by one route only: a named human cleared it
through every stage of the review tool — checklist complete, Tier 3
compliance sign-off where required, final approval recorded — and then moved
the file here by hand.

Nothing in the pipeline writes to this directory. The drafting agent stops at
`content/drafts/`; there is no code path from draft to published. The
repurposing agent *reads* from here and refuses any path outside it.
